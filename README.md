Требования

* **Python:** 3.10 или выше.
* **API Key:** Получите ключ в [Google AI Studio](https://aistudio.google.com/).
* **Библиотеки:**
    * `PyAudio` — для работы с микрофоном и динамиками.
    * `google-genai` — официальный SDK для работы с Gemini 2.5.
    * `numpy` — для обсчета громкости звука в реальном времени.
